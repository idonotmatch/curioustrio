# Summary Tab Mockups

These mockups explore a calmer, more intentional Summary tab hierarchy.

## Shared principles

- Make the top of the page a single monthly-state hero
- Show one featured insight instead of a tall insight stack
- Collapse operational status into a compact activity digest
- Keep quick actions separate from financial state

## Mockups

- `summary-on-track.svg`
  - solo user
  - healthy month
  - one lightweight insight
- `summary-over-budget.svg`
  - user is running ahead of usual pace
  - one stronger featured insight with a clear callout
- `summary-household.svg`
  - household context
  - queue and imports folded into a unified digest

## Key UX recommendation

If we only change one thing, it should be this:

- merge budget status, pace vs usual, and one plain-language takeaway into a single hero section

That gives the page a clear first answer:

- How am I doing?
- What matters most right now?
- What should I look at next?
